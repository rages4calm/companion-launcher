# Changelog

## 0.2.0

- Added an Avalonia UI host for Linux/macOS and Android, with responsive handheld navigation.
- Added desktop process service and Android embedded-activity launch bridge.

- Added portable interaction/rendering tests and Windows/Linux/macOS/Android CI.
- Retained the existing Windows Forms interface and its regression checks.
- Documented per-game integration, platform requirements and device-testing limits.

## 0.1.0
